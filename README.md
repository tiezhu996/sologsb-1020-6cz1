# 档案元数据核对台 · 可对账版本链

`sologsb-1020` 是一个用于口述史与手稿档案元数据比对的**本地优先**前端工作台，使用 Qwik、TypeScript 与 Qwik UI 构建。数据层以**批次版本链（DAG）+ 不可变快照 + 三方接续合并**为核心，解决多人离线核对后“后导入压掉前人结论、看不出各方改过哪版”的问题。

## 核心机制

### 版本链与共同祖先

- 每条结论（记录字段、候选裁决、合并选择）都记录在**批次快照**中；批次有祖先指针，形成可追溯的 DAG。
- **离馆出包**：封存当前工作批次为检查点（共同祖先），下载含全量快照的离线核对包；馆内可继续工作。
- **回馆汇入**：封存本馆侧检查点，建立 `offline-edit` 批次与 `import-merge` 汇入节点（两个父批次），按最近共同祖先做**三方接续**：
  - 只一边改过的内容**自动生效**，并登记来源修订批次；
  - 同字段 / 同候选两边改法不同，列入**分歧清单**，展示共同祖先、馆内、离线三份结论与来源修订、核对人；
  - **分歧裁决前不能合并记录，也不能导出**。
- 连续多轮离馆/回馆时，上一轮汇入节点本身成为下一轮的共同祖先。

### 现行规则重算与退回复核

- 修改记录的**标题、日期、人物、地点**后，相关候选按现行评分规则重新计算分数与依据。
- 已确认、已忽略、已合并的结论若旧依据与现行字段不符，**携带旧依据、旧状态与退回原因回到待复核**（界面以“退回”标记展示）。
- 不再满足阈值或记录被接替的结论同样退回。

### 来源批次与审计

- 记录、候选、合并、修订（revision）、审计（audit）全部携带 `batchId / sourceBatchId`；字段级来源可追到具体批次与进入方式（seed/编辑/补录/合并/裁决）。
- 合并生成接替记录，原记录保留并标记 `supersededBy`，合并字段逐字段保留来源批次。
- 导出核对结果写明完整**祖先批次链**与字段级修订来源；存在未裁决分歧时拒绝导出。

### 安全与兼容

- 汇入在**草稿**上完成：包损坏、结构不合法、workspace 不符或中途失败，原工作区字节不变，可直接重试。
- v1 旧版工作区自动迁移：补建 `legacy-import` 迁移根与祖先链，旧结论按现行规则重算（依据过期的退回待复核）。
- 撤销 / 重做只作用于**当前开放工作批次**，封存批次永不回滚；离馆/回馆/裁决后清空撤销栈。
- 载入时做批次链完整性检查（断链、孤儿快照、悬空引用）。

## 功能

- 补录 A / B 两组记录（JSON 数组、制表符 / 竖线分隔文本），新记录归属当前批次。
- 按标题、日期、人物、地点、编号加权匹配，候选评分、依据与退回历史可见。
- 键盘密集复核：J/K 移动、Enter 合并、C/R 确认或忽略、X 跳分歧，支持批量操作。
- 逐字段合并：A / B 来源并排（含来源批次），可单独保留或拼接。
- 分歧裁决页：三方结论对照，一键采用馆内 / 离线结论。
- 版本链页：按深度展示全部批次、祖先关系与当前工作位置。
- 修订 / 审计页：所有改动带来源批次，自动接续的离线修订单独标注。
- 离线 localStorage 保存、分批窗口渲染，大量记录不卡顿。

## 技术栈

- Qwik 1.20 · TypeScript 5.9 · Qwik UI Headless · Vite 7
- 纯前端本地运行，无后端；版本链核心逻辑（`src/utils/version.ts`、`src/utils/matching.ts`）与框架解耦，可在 Node 下直接测试。

## 开发

```bash
npm install
npm run dev          # 开发服务（Vite 默认端口）
npm test             # 47 项版本链核心流程断言（esbuild 打包到 node 运行）
npm run test:dom     # 生产构建 + jsdom 挂载冒烟测试
npm run build        # 类型检查 + 生产构建到 dist/
```

## 数据模型概览

```
BatchNode (root / work / work-checkpoint / offline-edit / import-merge / legacy-import)
  └─ parents[] ──→ 共同祖先由祖先闭包中深度最大的批次确定
Snapshot（每个封存批次一份）
  ├─ records: RecordSnap     字段值 + origins(字段级来源) + supersededBy
  ├─ decisions: DecisionSnap 候选裁决 + basis(评分依据) + reopened(旧依据退回)
  └─ merges: MergeSnap       逐字段选择 + 值 + 来源
WorkspaceState：batches DAG + 封存快照 + 当前开放批次快照 + conflicts + revisions + audit
```

离线包格式 `archive-check-offline/2`，导出包格式 `archive-check-export/2`。
