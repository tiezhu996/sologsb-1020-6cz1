# 档案元数据核对台

`sologsb-1020` 是口述史与手稿档案元数据比对的本地优先工作台，Qwik + TypeScript 构建。v2 起工作台是一条**可对账的版本链**：档案员离线核对后回馆合并核对包时，系统按共同祖先做三方接续，而不是让后导入覆盖前人结论。

## 版本链与接续规则

- **修订与批次**：每次确认 / 忽略、批量复核、字段修订、合并、导入都产生一个修订节点（根修订无父，普通修订单父，接续合并为双父节点）和一个来源批次；记录字段、候选结论、合并裁决、审计条目都带来源批次与修订。
- **导入按共同祖先接续**：导入核对包先校验 SHA-256，再在合并版本图中定位最低共同祖先。
  - 本账自祖先以来无独立修订 → **快进**，直接采用来件头；
  - 只有一边改过的记录字段 / 候选结论 / 合并裁决 → **自动生效**并保留对方来源批次；
  - 同一候选或同一字段双方处理不同 → 列出**共同祖先、本账结论、对方结论及各自来源修订**，逐条裁决；**未全部裁决前不能接续合并、不能再合并记录、不能导出**。
- **规则字段变化触发重算**：标题、日期、人物、地点被修订（或接续生效）后，相关候选按现行规则（`rules-2026-10`）重新评分；已确认、已忽略、已合并的结论在相似度实质变化或候选消失时，**带旧依据（原状态、原评分、原批次、重置原因）回到待复核**，对应合并记录标记「旧依据」。
- **撤销 / 重做只影响当前工作区**：沿本地修订内容快照前后跳转，版本链与审计轨迹保留不动。
- **旧数据升级补祖先**：v1 扁平工作区和无版本链旧核对包会自动补一个祖先根修订并回填字段来源，再按外来包接续。
- **中断可重试**：持久化先写暂存键再正式提交；写入中断后下次启动从暂存恢复；损坏的包（校验和不符、JSON 截断、头修订缺失）一律拒绝，工作区原样不动，可重新选择重试。
- **导出可对账**：核对包写明工作区、头修订、最近共同祖先（含祖先内容快照）、完整修订图、批次、审计与 SHA-256 校验和，对方可离线核对后再回并。

## 功能

- 导入 A / B 两组记录（JSON 数组、制表符或竖线分隔文本）或他人导出的核对包。
- 按标题、日期、人物、地点、编号加权匹配，显示综合分、字段依据与规则版本。
- 键盘密集复核：J/K 移动、Enter 合并、C/R 确认或忽略，支持批量操作。
- 合并时逐字段并排展示 A / B 来源与批次，可单独保留任一侧或拼接；生成合并记录并保留原记录编号，旧合并被重新合并时标记取代。
- 版本链弹窗展示根修订、单父修订与双父接续节点（共同祖先、来件头）。
- 大量记录采用分批窗口渲染，候选计算限制每侧候选数，避免一次挂载全部行。

## 开发

```bash
npm install
npm run dev
```

类型检查与生产构建：

```bash
npm run build
```

版本链引擎冒烟测试（快进、分叉冲突、裁决锁定、规则重算、损坏包、合并回退等 40+ 断言）：

```bash
npm run test:engine
```

## 数据说明

全部数据保存在当前浏览器 localStorage（含修订内容快照，仅保留根修订、来件祖先与最近修订以控制容量）。任何导入都不会自动覆盖人工结论；需要双方取舍时必须显式裁决。
